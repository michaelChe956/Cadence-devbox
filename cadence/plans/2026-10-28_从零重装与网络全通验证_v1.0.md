## 0. 会保留 / 会丢弃

| 保留（**绝不删**） | 丢弃（可重建） |
|---|---|
| 17 个命名卷：`cadence-jdks`（JDK 选择）、`cadence-m2`/`gradle`/`npm*`/`uv`/`pip`（构建缓存）、`cadence-claude`/`codex`/`pi`/`kimi`/`agents`/`omp`（agent 登录态）、中间件数据卷 | 容器、镜像、网桥、relay 通道（portproxy / nft / systemd 单元）、安装目录里的 `.env` 与派生文件 |

## 1. 备份要带走的两样

```powershell
New-Item -ItemType Directory -Force D:\testpodman\keep | Out-Null
Copy-Item D:\testpodman\cadence\cadence-box.yaml D:\testpodman\keep\ -Force   # 密钥/模型配置
Copy-Item D:\testpodman\cadence\relay.json       D:\testpodman\keep\ -Force   # VPN 通道清单
```

## 2. 拆 relay 通道（必须在删 machine / 删容器之前）

```powershell
cd D:\testpodman\Cadence-devbox
powershell -ExecutionPolicy Bypass -File .\devbox\relay.ps1 -InstallDir D:\testpodman\cadence -Teardown
```

复核（应全空 / 无表）：

```powershell
netsh interface portproxy show all
podman network ls --format "{{.Name}}" | Select-String cadence
podman machine ssh 'sudo nft list table ip cadence_dnat'
```

## 3. 删容器与镜像（**不要删卷**）

```powershell
podman rm -f cadence_devbox cadence_devbox_1 devbox 2>$null
podman-compose -f D:\testpodman\cadence\stack\compose.yaml down
podman images --format "{{.Repository}}:{{.Tag}}" | Select-String "cadence-devbox|/cadence/devbox" |
  ForEach-Object { podman rmi -f $_ }
```

`podman volume ls --format "{{.Name}}" | Select-String cadence` 必须仍是 17 个。

## 4. 准备安装目录（三件事）

```powershell
# ① compose.yaml 必须带固定容器名
Select-String -Path D:\testpodman\cadence\stack\compose.yaml -Pattern container_name
#    → container_name: cadence_devbox（没有就 Copy-Item .\devbox\compose.yaml 覆盖）

# ② 建 CHANGES.md：否则容器启动时 entrypoint 用镜像内置模板覆盖 compose.yaml
@'
# 本地改动记录（有本文件时 entrypoint 不再用镜像内置模板覆盖 stack 目录）
- compose.yaml：devbox 服务固定容器名 cadence_devbox
'@ | Set-Content -Encoding utf8 D:\testpodman\cadence\stack\CHANGES.md

# ③ 删掉 .env，让安装器重新生成（含镜像键）
Remove-Item D:\testpodman\cadence\stack\.env -Force
```

## 5. 安装（必须带 `-InstallDir`）

```powershell
cd D:\testpodman\Cadence-devbox
powershell -ExecutionPolicy Bypass -File .\devbox\install.ps1 `
  -InstallDir D:\testpodman\cadence `
  -Workspace D:/ideaWorkspace/tydicPowerCenterNew
```

中途「请编辑 cadence-box.yaml … 按回车」→ 直接回车（文件已在）。

期望：`生成安装目录 D:\testpodman\cadence` → 无「stack\.env 已存在」警告 → 无「未按固定名创建容器」警告 → `devbox 已就绪`。

## 6. 验收（容器 / 卷 / 权限）

```powershell
podman ps -a --format "{{.Names}}  {{.Status}}"      # 只有 cadence_devbox(Up) + mysql + redis
Get-Content D:\testpodman\cadence\stack\.env         # 三行：WORKSPACE / IMAGE / PROFILES
podman logs --tail 12 cadence_devbox                 # 出现「就绪」
podman exec cadence_devbox ls -ld /home/dev/.cadence # 属主必须 dev dev
podman exec cadence_devbox bash -c "jdk list; du -sh ~/.m2/repository 2>/dev/null; ls ~/.claude ~/.codex ~/.omp"
```

**若 `jdk` 报「状态目录 /home/dev/.cadence/jdks 不可写」**（老卷属主是 root）：

```powershell
podman exec -u root cadence_devbox chown -R dev:dev /home/dev/.cadence
podman stop cadence_devbox; podman start cadence_devbox
podman logs --tail 8 cadence_devbox
```

## 7. 恢复 VPN 通道

```powershell
Copy-Item D:\testpodman\keep\relay.json D:\testpodman\cadence\relay.json -Force
powershell -ExecutionPolicy Bypass -File .\devbox\relay.ps1 -InstallDir D:\testpodman\cadence
# 三问全回车 → 期望 8 条桥接 OK + 8 条真实地址 OK（DNAT 生效）
powershell -ExecutionPolicy Bypass -File .\devbox\relay.ps1 -InstallDir D:\testpodman\cadence -Status
# 期望 hop1~hop4 全 OK，VM 段每服务 active、DNAT 逐条 OK
```

## 9. 判定表

| 现象 | 根因 | 处置 |
|---|---|---|
| compose 建出 `cadence_devbox_1` | compose.yaml 被镜像内置模板覆盖（无 CHANGES.md） | 建 `stack\CHANGES.md` 后重建容器 |
| 安装器装到 `<仓库>\cadence` | 没传 `-InstallDir` | 清理那套后带 `-InstallDir` 重跑 |
| 容器 Exit 1 + `mkdir /home/dev/.cadence/logs: Permission denied` | `.env` 缺 `CADENCE_DEVBOX_IMAGE` → 回落最早版镜像 | 新安装器会自动补写该键；手工修：在 `.env` 写入正确镜像后重建 |
| `jdk` 报状态目录不可写 | `cadence-jdks` 卷属主是 root | 见 §6 的 chown |
| 第 3/5 条 FAIL 但第 4 条 OK | DNAT 规则缺失 | `podman machine ssh 'sudo nft list table ip cadence_dnat'`，或重跑 `relay.ps1` |
| 第 4 条也 FAIL | relay 通道没建起来 | 看 `-Status` 的 hop1/hop2 |
