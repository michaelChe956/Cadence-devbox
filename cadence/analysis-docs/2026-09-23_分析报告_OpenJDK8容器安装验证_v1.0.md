# OpenJDK 8 容器安装验证

## 范围与结论

Plan Task 1 的隔离安装验证通过：本机 Linux amd64 Podman 容器中，使用 `ghcr.io/michaelche956/cadence-devbox:1.0.0` 镜像（Ubuntu 24.04.4、默认 uid 1000 `dev`、内置 Temurin 21.0.12.1），从镜像内配置的 USTC Adoptium 签名 apt 仓库下载 Temurin 8 完整 JDK 包，归档 SHA-256 与 apt 元数据一致，解包至临时隔离目录；以普通 `dev` 用户执行 `java` 和 `javac` 均显示 8。未修改目标镜像、持久卷或系统 Java。此结论只覆盖当前实测网络，不保证所有大陆运营商线路始终可达。

## 发行物与信任链

- apt 源采用 `signed-by=/etc/apt/keyrings/adoptium.gpg`；镜像内密钥 UID 为 `Adoptium GPG Key (DEB/RPM Signing Key) <temurin-dev@eclipse.org>`，指纹 `3B04 D753 C905 0D9A 5D34 3F39 843C 48A5 65F8 F04B`。独立从发行方安装说明 https://adoptium.net/installation/linux/ 指定的 https://packages.adoptium.net/artifactory/api/gpg/key/public 获取密钥，运行 `curl -fsSL https://packages.adoptium.net/artifactory/api/gpg/key/public | gpg --show-keys --with-fingerprint`，得到同一指纹；容器中 `apt-get update` 在该签名源上成功。
- `apt-cache show temurin-8-jdk=8.0.504.0.0+1-0` 给出的包路径 `pool/main/t/temurin-8/temurin-8-jdk_8.0.504.0.0+1-0_amd64.deb`、大小 `85228180` 字节、SHA-256 `8747c07903772fb7fcfff803e06bd4761124def9d2aef781c98c745c10e6841a`。下载后 `sha256sum` 实测同值。apt 使用独立从发行方获取并比对指纹的公钥校验签名仓库的 Release/Packages 链；未以 HTTP 状态码代替完整性验证。
- 包声明 `java-compiler` 和 `java8-sdk` 等能力；实际解包包含 `bin/java` 和 `bin/javac`。包的依赖包括 `adoptium-ca-certificates`、`java-common`、`libasound2` 等；隔离解包运行验证通过，但完整系统包依赖、许可通知与 Windows Podman machine 大陆线路未在此实验逐一验证，实施时须补足。

## 复现实验命令与观测

以本机已有目标镜像创建一次性容器，不调用应用 entrypoint；容器内执行：

```bash
podman run --rm --user root --entrypoint /bin/bash ghcr.io/michaelche956/cadence-devbox:1.0.0 -lc 'set -euo pipefail; apt-get update -qq; apt-cache show temurin-8-jdk=8.0.504.0.0+1-0 | sed -n "1,32p"; mkdir -p /tmp/jdk8-probe; cd /tmp/jdk8-probe; apt-get download temurin-8-jdk=8.0.504.0.0+1-0; sha256sum ./*.deb; dpkg-deb -x ./*.deb unpack; chown -R dev:dev unpack; su dev -s /bin/bash -c "unpack/usr/lib/jvm/temurin-8-jdk-amd64/bin/java -version; unpack/usr/lib/jvm/temurin-8-jdk-amd64/bin/javac -version"'
```

观测到 `apt-get update` 后候选版本 `8.0.504.0.0+1-0`；从 USTC 获取 85.2 MB 包耗时约 6 秒（容器输出）；校验值与 Packages 元数据一致。核心原始输出：

```text
SHA256: 8747c07903772fb7fcfff803e06bd4761124def9d2aef781c98c745c10e6841a
8747c07903772fb7fcfff803e06bd4761124def9d2aef781c98c745c10e6841a  ./temurin-8-jdk_8.0.504.0.0+1-0_amd64.deb
openjdk version "1.8.0_504"
OpenJDK Runtime Environment (Temurin)(build 1.8.0_504-b01)
OpenJDK 64-Bit Server VM (Temurin)(build 25.504-b01, mixed mode)
javac 1.8.0_504
```

该实验容器使用 `--rm`，产物随容器删除。运行期仍须固定经签名元数据核实的版本与 SHA-256，并在下载失败时保持旧版本不变；完整系统包依赖、许可通知及 Windows Podman machine 网络需在实施后续验证。
